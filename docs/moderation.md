# 운영자 화면과 계정 정지

신고를 보고 의견을 가리거나, 올린 게임을 내리거나, 계정을 정지하는 곳입니다. 화면은 `/web/admin.html`이고,
운영자로 로그인하면 상단 메뉴 끝에 "운영"이 보입니다. 코드는 [server/internal/admin](../server/internal/admin/admin.go)에 있습니다.

## 운영자 정하기

운영자는 환경변수 `ADMIN_IDS`에 적은 계정입니다 (쉼표로 여러 개). 계정 id는 로그인한 뒤 `/api/me`의 `id`(`m_…`)입니다.
운영자는 서버를 다시 켜야 바뀝니다. 화면에서 운영자를 더하거나 빼는 기능은 없습니다.

운영(boardmadang.com)에서는 Secret Manager의 `admin-ids`에 넣고 `deploy/deploy.sh`로 다시 배포합니다.
값을 붙여 넣고 Enter, 그다음 Ctrl+D로 끝냅니다.

```bash
gcloud secrets create admin-ids --project boardmadang --data-file=-
# 나중에 바꿀 때
gcloud secrets versions add admin-ids --project boardmadang --data-file=-
```

운영자는 정지할 수 없습니다 (자기 자신도). 운영자를 빼려면 `ADMIN_IDS`에서 지우고 다시 배포합니다.

## 신고 목록

신고(`POST /api/reports`)는 `DATA_DIR/reports.jsonl`에 쌓입니다. 운영자 화면은 이것을 대상(게임 하나, 또는 게임의 의견 하나)별로 묶어 보여줍니다.

- **새 신고**: 그 대상에 한 마지막 조치보다 늦게 온 신고가 있으면 새 신고입니다. 조치를 한 번도 안 했으면 모두 새 신고입니다.
- 조치하거나 "문제없음"(dismiss)을 누르면 처리한 것이 됩니다. 처리한 대상에 새 신고가 오면 다시 새 신고로 올라옵니다.
- "처리함" 표시를 따로 저장하지 않고 운영 기록(`admin.jsonl`)의 마지막 조치 때로 정합니다.
- 새 신고가 있는 대상이 먼저, 그다음 처리한 대상(최근 50개)이 나옵니다. 각각 마지막 신고가 최근인 것부터입니다.

의견은 지금 글을 그대로 보여줍니다 (신고가 쌓여 가려진 글도). 쓴 사람이 지운 의견은 "쓴 사람이 지움", 탈퇴로 지워진 의견은 "의견이 없음"입니다.
레포에 있는 게임(`games/`)은 화면에서 내릴 수 없습니다. 고치거나 빼려면 PR로 합니다.

## 조치

| 조치 | 하는 일 |
|---|---|
| 의견 가리기 (`comment.hide`) | 신고 수와 상관없이 가립니다. 다른 사람에게는 "가려진 의견"으로 보입니다 |
| 의견 보이게 (`comment.show`) | 신고가 쌓여 가려진 의견을 다시 보이게 합니다. 그 뒤로 신고가 더 와도 가려지지 않습니다 |
| 게임 내리기 (`game.block`) | 올린 게임을 로비와 클리어 기보에서 뺍니다. 주인이 "다시 올리기"를 하거나 새 버전을 등록해도 나오지 않습니다 |
| 게임 되살리기 (`game.unblock`) | 내린 게임을 되살립니다. 주인이 직접 내린 게임(내림)이면 여전히 빠져 있습니다 |
| 정지 (`user.suspend`) | 1일, 7일, 30일, 영구 중에서 골라 계정을 정지합니다 |
| 정지 풀기 (`user.unsuspend`) | 기한 전에 정지를 풉니다 |
| 문제없음 (`dismiss`) | 바꿀 것 없이 그 대상의 신고를 처리한 것으로 칩니다 |

조치마다 메모를 남길 수 있습니다 (300자까지). 정지와 정지 풀기를 신고 카드에서 하면 그 대상의 신고도 처리한 것이 됩니다.
내린 게임의 코드는 지우지 않습니다. 이미 둔 대국의 기보를 다시볼 수 있어야 하기 때문입니다.

## 계정 정지

정지된 계정은 **쓰기만 막힙니다**. 서버가 막고, 화면은 안내를 보여줍니다.

| 막힘 (`403 {"error":"suspended"}`) | 그대로 됨 |
|---|---|
| 의견 남기기, 신고 | 빠른 매칭, 열린 방에 들어가기, 관전 |
| 방 만들기 (웹소켓 `error` "suspended") | 기보 보기, 내 프로필 보기 |
| 게임 올리기, 등록, 등록 정보 고치기, 내리기와 다시 올리기 | 내 의견 지우기 |
| 이름 바꾸기 | 로그아웃, 탈퇴 |

- 기한이 지나면 저절로 풀립니다. 서버가 요청마다 지금 시각과 비교하므로 따로 풀어 줄 일이 없습니다.
- 정지는 세션 토큰에 들어 있지 않고, 요청마다 계정 기록에서 읽습니다. 그래서 정지하면 다음 요청부터 바로 막힙니다.
  웹소켓은 붙어 있는 동안 신원을 다시 읽지 않지만, 방을 만들 때는 다시 읽습니다. 이미 시작한 대국은 그대로 끝까지 둡니다.
- 내 프로필, 게임 창의 의견 칸과 방 만들기, 게임 등록 화면에 "언제까지 정지되었는지"가 보입니다 (`/api/me`의 `suspended`, `suspendedUntil`).
- 정지된 사람이 탈퇴하고 같은 곳으로 다시 로그인하면 새 계정이라 정지가 없습니다. 이것은 막지 않습니다
  (탈퇴하면 로그인한 곳의 번호도 지우기 때문입니다). 같은 사람이 계속 문제를 일으키면 그때 다시 정지합니다.

## 저장하는 곳

모두 `DATA_DIR` 아래에 한 줄씩 덧붙이는 파일입니다.

| 파일 | 줄 |
|---|---|
| `admin.jsonl` | 운영 기록. `{"action","game","comment","user","days","note","by","at","until"}`. 운영자 화면에는 최근 100개만 보입니다 |
| `accounts.jsonl` | 정지 `{"op":"suspend","id","until"}`(영구면 `until` 없음)와 풀기 `{"op":"unsuspend","id"}` |
| `comments/<게임>.jsonl` | 운영자의 결정 `{"op":"mod","id","mod":"hidden"\|"shown","by"}` |
| `uploads/<id>/game.json` | 내린 게임은 `"blocked": true` |
| `reports.jsonl` | 받은 신고 (internal/comment가 씀) |

## API

운영자만 됩니다. 쿠키가 없으면 401, 운영자가 아니면 `403 {"error":"admin only"}`입니다.

| 요청 | 하는 일 |
|---|---|
| `GET /api/admin` | 신고 목록(`targets`), 나오는 계정(`users`), 정지된 계정(`suspended`), 최근 운영 기록(`log`), 고를 수 있는 정지 기간(`days`) |
| `POST /api/admin/actions` | 조치 하나. `{"action":"user.suspend","user":"m_…","days":7,"game":"…","comment":"…","note":"…"}` → `{"ok":true}` |

조치가 안 되면 400(`bad action`, `cannot suspend an admin`, `too long`)이나 404(`not found`)입니다.
POST는 JSON 본문만 받습니다. 다른 사이트의 폼은 이런 본문을 보낼 수 없고, fetch는 미리 확인(preflight)에서 막힙니다.
