## 1. 공개 전에 꼭 할 것

### 1-1. 사이트에서 게임 올리기

다 됐습니다 ([server/internal/upload](../server/internal/upload), [docs/protocol.md](protocol.md#게임-올리기-serverinternalupload)).
"게임 등록" 화면에서 zip 올리기 → 자동 검사 → 직접 깨기와 썸네일 → 등록 정보 → 등록까지 합니다.
올린 게임은 내 프로필(상단의 내 이름)의 "내가 올린 게임"에서 내리거나, 등록 화면을 고치기로 열어(`?edit=<id>`) 등록 정보만 고칩니다.
개발 서버에서는 예전처럼 레포 게임의 등록 정보를 고칩니다.

- [x] **업로드 API** (계정만): `POST /api/drafts`로 초안을 올리고 `POST /api/drafts/{draft}/publish`로 등록
  - `npx boardmadang pack`이 만든 zip을 받음 (300KB 이하)
  - 파일 규칙: `.js`, `.mjs`와 맨 위의 `listing.json`, `thumbnail.json`만 (다른 JSON은 버전에 안 들어가서 거절), 폴더 밖 경로와 점으로 시작하는 이름 거절, 코드 256KB 이하
  - 버전별 저장: `DATA_DIR/uploads/<id>/<버전>/`. 게임 주인(계정) 기록, id 중복 확인 (레포 게임 id도 막음)
  - 하루 등록 5번, 초안은 한 시간에 30번 ([abuse-and-limits.md](abuse-and-limits.md))
  - 등록 정보와 썸네일은 서버가 다시 검사 (`listing.js`, `check.js`의 규칙을 Go로 옮김)
- [x] 올라온 게임도 `/api/games`에 나오고, `/uploads/<id>/<버전>/…`에서 내보내기 (실행기용 CORS, 버전이 내용의 해시라 오래 캐시)
- [x] **새 등록 화면**: zip 올리기 → 실행기 안에서 자동 검사(`sdk/check.js`) → 등록 정보 → 등록
- [x] 등록 화면에 클리어 체크와 썸네일 찍기 넣기 (zip의 `thumbnail.json`, 지금 등록된 썸네일, 직접 찍은 판 중에서)
- [x] **클리어 체크** (슈퍼 마리오 메이커 2처럼, [clear.go](../server/internal/upload/clear.go))
  - 혼자 양쪽을 둬서 `result()`가 승자를 정해야 통과. 무승부, 기권, `maxActions` 도달은 안 됨
  - 그 판(시드, 상태를 바꾼 행동, 코드 버전)을 "제작자 클리어 기보"로 저장하고 로비의 게임 창에서 다시보기로 연결
  - 코드를 고쳐 버전이 바뀌면 다시 해야 함 (같은 버전을 다시 등록하면 전에 깬 판을 그대로 씀)
  - 클리어 체크 전에 올린 게임은 클리어 기보가 없습니다. 다음에 새 버전을 올릴 때 깨면 됩니다
- [x] 등록 정보만 고치기, 게임 내리기와 다시 올리기 (`PATCH /api/uploads/{id}`, 한 시간에 30번, 하루 등록 수에는 안 셈)
  - 내린 게임은 로비와 클리어 기보에서 빠지지만 코드는 남겨 이미 둔 대국의 기보를 다시볼 수 있음. id도 주인의 것
- [x] 올린 게임의 옛 버전 코드 보관 (`DATA_DIR/uploads/<id>/<버전>/`)
- [x] 기보는 그 버전으로 다시보기 (올린 게임만. 레포 게임은 옛 코드가 없어 지금처럼 버전이 다르다고 알림)

## 운영 메모

- **배포**: 커밋한 뒤 `deploy/deploy.sh`. 서버가 다시 켜지므로 진행 중인 대국이 없을 때 합니다 (`https://boardmadang.com/api/live`가 `[]`인지 확인).
- **npm 배포**: `sdk/package.json`의 버전을 올리고 `cd sdk && npm publish`. 2단계 인증 화면이 열리는데, 휴대폰에 저장한 패스키라면
  그 인증 주소를 휴대폰에서 열어 인증합니다. 같은 버전 번호는 다시 쓸 수 없습니다.
- **브랜치**: `main`에서 기능 브랜치를 따서 PR로 합칩니다. 합치면 브랜치는 자동으로 지워집니다.
  `cla-signatures` 브랜치는 CLA 봇이 서명을 쌓는 곳이라 지우지 않습니다.
