# 예제 게임

[게임 API](../sdk/README.md)로 만든 예제입니다. 플랫폼 API가 정말 범용인지 검증하는 역할도 합니다.

| 게임 | 폴더 | 보드 | 이 게임이 검증하는 것 |
|---|---|---|---|
| 틱택토 | [`tictactoe/`](tictactoe/index.js) | 3×3 칸 | 전체 흐름 (매칭 → 대국 → 결과 → AI 학습) |
| 바둑 | `go/` (예정) | 9×9 교차점 | 교차점 보드, 따내기, 패, `pass` 특수 행동, 계가 |
| 체스 | `chess/` (예정) | 8×8 칸 | 선택 → 이동 2클릭, 보드 뒤집기, 프로모션, 무승부 |

## 구현 메모

- **바둑**: 계가는 Tromp-Taylor 규칙(판 위 내 돌 + 내 돌로만 둘러싸인 빈 점)을 쓰면 죽은 돌 합의가 필요 없습니다.
  덤을 6.5나 7.5처럼 .5로 두면 무승부가 생기지 않습니다.
- **체스**: perft 테스트로 수 생성을 검증합니다. 시작 포지션 깊이 1~4의 정답은 20 / 400 / 8,902 / 197,281입니다.
  캐슬링·앙파상·프로모션은 시작 포지션에서 깊이 4까지 나오지 않으므로, chessprogramming.org의
  "Perft Results" 페이지에 있는 테스트 포지션(Kiwipete 등)도 같이 돌립니다.
- 판에 안 보이는 상태(캐슬링 권리, 앙파상, 패 자리, 선택 중인 기물)는 `observe()`로 내보냅니다.
