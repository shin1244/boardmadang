# AI 학습 (예정)

업로드된 창작 게임으로 AI를 자동 학습시키는 파이프라인입니다. 설계 배경은
[docs/architecture.md](../docs/architecture.md#ai-학습-예정)에 있습니다.

## 방식: AlphaZero (신경망 + MCTS 자기대국)

PPO는 쓰지 않습니다. 승패 하나만 보상으로 받고 수읽기를 못 해서 바둑·체스 같은 게임에서 약하기 때문입니다.
AlphaZero는 같은 설정으로 여러 게임을 학습시킬 수 있는 범용 방식이고, 작은 게임에도 그대로 통합니다.

```
자기대국 (MCTS로 매 수 탐색)
  → (국면, 탐색이 고른 수의 분포, 최종 승패) 를 학습 데이터로 저장
  → 신경망 학습: 정책(어디에 둘지) + 가치(누가 유리한지)
  → 새 신경망으로 다시 자기대국
```

## 계획

1. **환경 어댑터**: 게임 JS를 Node 워커에서 실행합니다.
   - 관측: `view()` + `observe()` → rows × cols × 채널 텐서
   - 행동: `rows × cols` 클릭 + `specialActions`, 둘 수 있는 수는 `legal()`
   - MCTS용 복사: 상태가 JSON이라 복사가 공짜입니다
2. **모델**: 완전 합성곱 정책·가치 신경망 (보드 크기와 무관한 구조)
3. **병목 대비**: 게임 로직(JS)과 학습(Python)이 다른 프로세스라, 여러 워커가 낸 국면을 모아서(batch)
   한 번에 신경망에 넣는 구조가 필요합니다.
4. **산출물**: 체크포인트 + 탐색 횟수 조합으로 난이도 여러 단계, 자기대국 기반 밸런스 리포트
5. **작은 게임**: 국면 수가 상한 아래면 학습 대신 완전 탐색으로 풀어 확정 결론을 냅니다.
6. **유명한 게임**: 학습하지 않고 기존 엔진(KataGo, Stockfish 등)을 연결합니다.

## 예산과 제한

학습은 "강해질 때까지"가 아니라 **정해진 GPU 시간만큼만** 돌립니다.
학습을 시작하는 조건과 제한값은 [docs/abuse-and-limits.md](../docs/abuse-and-limits.md)에 있습니다.
MVP에서는 관리자가 고른 게임만 학습합니다.

## 첫 목표

틱택토를 처음부터 끝까지: 학습 (CPU로 충분) → 완벽하게 두는 AI와 대국.
